# سبيدي مندوب — تطبيق أندرويد

تطبيق المندوب: يسجّل بدء الفترة وإنهاءها (تظهر في سجل الفترات بمنصة التتبع)، ويرسل موقع المندوب كل دقيقة **أثناء الفترة فقط**، حتى والشاشة مغلقة. المدير يتابع من **منصة التتبع** (مستودع speedy-tracking).

## بناء ملف APK (تلقائياً على GitHub)

لا يحتاج أي برنامج على جهازك؛ GitHub يبني التطبيق عند كل رفع.

1. أنشئ مستودعاً جديداً باسم `speedy-driver` (Public).
2. ارفع كل محتويات هذا المجلد، بما فيها مجلد `.github` (فيه ملف البناء).
3. **Settings ← Secrets and variables ← Actions ← New repository secret** وأضف:
   - `ANDROID_KEYSTORE_BASE64` — محتوى ملف التوقيع (من ملف speedy-driver-signing.txt)
   - `ANDROID_KEYSTORE_PASSWORD` — كلمة مرور التوقيع (من نفس الملف)
4. افتح تبويب **Actions** ← **Build Android APK** ← **Run workflow**. يستغرق البناء 8–12 دقيقة.
5. يظهر التطبيق في **Releases** على الرابط الثابت:
   `https://github.com/anasgusbi/speedy-driver/releases/latest/download/speedy-driver.apk`

> مفتاح التوقيع يجب أن يبقى نفسه دائماً؛ بدونه لا يمكن تحديث التطبيق فوق النسخة المثبتة. لا ترفع ملف التوقيع إلى المستودع.

## التحديثات
عدّل الملفات وارفعها؛ يُبنى إصدار جديد تلقائياً بنفس الرابط، ويثبّته المندوب فوق القديم.

## الملفات
| الملف | الوظيفة |
|---|---|
| `src/app.js` | منطق التطبيق: الدخول، بدء/إنهاء الفترة، إرسال الموقع |
| `src/config.js` | ربط Firebase ورابط Realtime Database وتكرار الإرسال |
| `www/` | واجهة التطبيق (يُبنى `www/app.js` تلقائياً من `src`) |
| `capacitor.config.json` | إعدادات تطبيق أندرويد |
| `scripts/patch-android.mjs` | أيقونة إشعار التتبع ورقم الإصدار |
| `.github/workflows/build-apk.yml` | بناء وتوقيع ونشر APK |

## تثبيت التطبيق على هاتف المندوب
1. افتح رابط التحميل على الهاتف ونزّل الملف.
2. اسمح بتثبيت التطبيقات من مصادر غير معروفة عند السؤال.
3. افتح التطبيق وسجّل الدخول برقم الدخول وكلمة المرور من المدير.
4. عند أول «بدء الفترة» اسمح بالموقع والإشعارات.
5. **مهم:** الإعدادات ← التطبيقات ← سبيدي مندوب ← البطارية ← **بدون قيود** (حتى لا يوقف الهاتف التتبع).
